# Sentinel AI

> Predictive intelligence for identifying early warning signs of future incidents

Sentinel AI is an LLM-powered research and forecasting project designed to analyze decades of news reports, detect recurring patterns that precede major incidents, and compare those patterns against current events to surface potential future risks.

This project focuses on identifying early warning signals for:

- natural disasters
- man-made disasters
- geopolitical conflicts and wars
- large-scale humanitarian crises

In addition to the forecasting model, the project includes a dashboard for visualizing results and triggering new predictions through a simple user interaction.

## What this project does

Sentinel AI aims to:

- ingest and analyze historical news data from the past several decades
- detect patterns that commonly appear before major incidents
- compare current news headlines and trends against historical precedents
- generate predictive insights with supporting context
- present results in a dashboard for easy review

## Dashboard features

The frontend dashboard includes:

- a summary of recent prediction results
- a visualization area for detected patterns and risk signals
- a button to trigger a fresh LLM-based prediction
- clear presentation of forecast output and supporting evidence

## Getting started

### Prerequisites

- Node.js and npm
- A working environment capable of running a frontend app locally

### Install dependencies

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
