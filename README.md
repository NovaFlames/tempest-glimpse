# Sentinel AI

create an LLM model that will predict future incidents like natural disasters, man made disasters, wars, etc.
The LLM needs to analyze news from past few decades and identify patterns preceding any major incident and then try identify similar patterns from recent news to predict future incidents.

Also, create a dashboard where LLM results can be viewed and it must have a button which will prompt the LLM to generate a prediction
